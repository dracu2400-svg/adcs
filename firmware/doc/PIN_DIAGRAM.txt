NOTES
================================================================================

1. VERIFY ALL PINS: This pin mapping is based on STM32L476RG capabilities
   and ADCS requirements. ALWAYS cross-reference with your actual PCB design
   before use.

2. ALTERNATE FUNCTIONS: Pins with peripheral functions (CAN, I2C, SPI, UART,
   TIM) must be configured with the correct alternate function (AF) number.
   See pin_config.h for AF definitions.

3. EXTERNAL COMPONENTS:
   - I2C requires 4.7kΩ pullup resistors on SCL and SDA
   - CAN requires TCAN330GD transceiver and 120Ω termination
   - All VDD pins need 100nF decoupling capacitors
   - VDDA needs 1µF + 10nF decoupling
   - NRST needs 100nF + 10kΩ pullup

4. POWER CONSIDERATIONS:
   - Total current for magnetorquers can be high (check INA226 readings)
   - Use separate power domain for actuators if needed
   - Monitor coil temperatures via TMP100 sensors

5. DEBUG ACCESS: Always keep PA13/PA14 (SWDIO/SWCLK) accessible for debugging.
   Do not reassign these pins unless absolutely necessary.

6. BOOT MODE: BOOT0 should be pulled low for normal operation. Can be
   connected to a jumper for firmware update mode if needed.
